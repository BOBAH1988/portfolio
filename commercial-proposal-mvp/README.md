# Черновик коммерческого предложения — MVP

Краткий README для демонстрационного статического прототипа инструмента для подготовки черновика коммерческого предложения.

## Название проекта

`commercial-proposal-mvp` — демонстрационный статический прототип инструмента для подготовки черновика коммерческого предложения.

## Цель

Создать чистый, валидный и легко расширяемый каркас для дальнейшей разработки инструмента подготовки черновиков коммерческих предложений.

## Границы MVP

Вне первой версии: скидки, налоги, PDF/DOCX, экспорт, общий итог КП, интеграции и внешние API.

## Технологии

Проект полностью статический:

- HTML;
- CSS;
- JavaScript.

Не используется:

- React;
- Vite;
- npm;
- Node.js;
- TypeScript;
- базы данных;
- бэкенд;
- API-ключи;
- внешние библиотеки;
- CDN.

## Запуск

Откройте файл `index.html` в любом современном браузере. Никакая сборка, сервер или зависимости не требуются.

## Статус

Демо-прототип функции «Добавление товара в черновик КП»:

- каталог демонстрационных товаров;
- добавление товара в черновик и проверка дубликатов;
- валидация количества как положительного целого значения;
- расчёт суммы позиции, статусы строк и inline-уведомления.

Реализация требует финального ручного прогона сценариев AC-01—AC-05 в браузере.
