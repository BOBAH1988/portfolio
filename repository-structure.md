# Структура репозитория

```text
portfolio/
├── README.md                    ← главная страница портфолио
├── money-path.md                ← PWA для учёта личных финансов
├── ZOO_opt.md           ← автоматизация почтовых процессов и управление клиентами
├── order-recommendations.md     ← система рекомендаций к заказу
├── vba-macros.md                ← автоматизация Excel с помощью VBA
├── goal-tracker.md              ← PWA «Трекер целей»
├── love-play.md                 ← PWA с играми
├── geekbrains.md                ← учебные аналитические проекты
├── repository-structure.md      ← этот файл
├── .gitignore                   ← служебные файлы ОС (.DS_Store)
├── commercial-proposal-mvp/     ← статический прототип черновика КП
│   ├── README.md                ← описание прототипа и его границ
│   ├── AI_CONTEXT.md            ← контекст проекта для AI-агентов
│   ├── index.html               ← разметка: каталог, черновик, уведомления
│   ├── styles.css               ← стили разметки и статусов
│   ├── app.js                   ← демо-товары, валидация, расчёт суммы
│   ├── requirements.md          ← требования к MVP
│   ├── test-cases.md            ← ручные тест-кейсы AC-01—AC-05
│   ├── docs/
│   │   └── test-assignment-response.md ← описание выполнения тестового задания
│   ├── assets/                  ← заготовка под изображения
│   └── screenshots/             ← заготовка под скриншоты прототипа
└── screenshots/                 ← обезличенные изображения
    ├── README.md                ← правила подготовки скриншотов
    └── actions-log.png          ← лог GitHub Actions
```

## Назначение файлов

- `README.md` — главная страница и краткая витрина портфолио.
- `money-path.md` — описание PWA для учёта личных финансов.
- `ZOO_opt.md` — описание автоматизации почтовых процессов и управления клиентами.
- `order-recommendations.md` — описание системы рекомендаций к заказу.
- `vba-macros.md` — описание Excel-макросов.
- `goal-tracker.md` — описание PWA-трекера целей.
- `love-play.md` — описание PWA с играми.
- `geekbrains.md` — учебные аналитические проекты.
- `repository-structure.md` — описание структуры репозитория.
- `.gitignore` — исключает служебные файлы macOS (`.DS_Store`).
- `commercial-proposal-mvp/` — статический прототип инструмента подготовки черновика коммерческого предложения; точка входа — `index.html`.
- `screenshots/` — обезличенные изображения для демонстрации проектов.

## Принцип организации

Страницы проектов намеренно лежат плоско: каждая страница проекта — отдельный файл
в корне. Посетитель открывает `README.md` и переходит по прямой ссылке
на нужный проект, не погружаясь в лишние уровни вложенности.

Вложенная папка одна — `commercial-proposal-mvp/`: там лежит работающий прототип
со своим README, требованиями и тест-кейсами. Ссылка на него ведёт
не на отдельную страницу-описание в корне, а в собственный README проекта.
