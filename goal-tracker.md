# Трекер целей — PWA для пошагового достижения целей

**Демо:** [bobah1988.github.io/goal-tracker](https://bobah1988.github.io/goal-tracker/)  
**Стек:** Vanilla JS, HTML/CSS, PWA, Service Worker, Firebase (Auth + Firestore),  
node:test + jsdom  
**Версия:** v1.2.50 (октябрь 2026), 337 автоматических тестов

## Идея

Перепробовал много сервисов постановки целей — все страдали одним: 
дедлайны давят, SMART обязателен, графики отвлекают от главного. 
Сделал свой трекер: **только цель и путь к ней**, без давления и рамок.

## Функционал

- **Дерево целей** — цель делится на подцели любой вложенности,
  прогресс считается автоматически от выполненных шагов.
- **Шаблоны** — шесть готовых наборов (здоровье, работа, обучение,
  финансы, отношения, отдых) с превью: можно добавить цели к существующей
  сфере или создать новую, повторы пропускаются.
- **Чек-листы** — к любому шагу можно прикрепить список мелких пунктов;
  частично отмеченный чек-лист даёт дробный вклад в прогресс (2/4 = половина).
- **Колесо баланса** — обзор всех сфер на одном экране, нажатие на сектор
  открывает дерево целей. Печать на A4 одной страницей и шеринг PNG 1080×1080
  в мессенджеры (Web Share с фолбэком в файл).
- **Хорошее сегодня** — необязательный дневник: запись о хорошем, история
  с пагинацией и блок «Победы за неделю» (недельная рефлексия с архивом
  отчётов).
- **«У меня будет»** — доска мечтаний: карточки «картинка + подпись»,
  порядок вручную, метка «Это я», плотность сетки 2/3/4, печать на A4.
  Фото синхронизируются между устройствами через Firestore (отдельные
  документы, сырые байты), локально кэшируются в IndexedDB — офлайн работает.
- **Поиск** — по названиям целей и пунктам чек-листов, с путём до совпадения
  (включая архив).
- **Приоритеты** — звёздочка ☆ выносит цель в блок «Главные цели»,
  максимум 5 одновременно.
- **Мягкое напоминание о сферах** — если к сфере две недели не возвращались,
  одно ненавязчивое предложение заглянуть. Без дедлайнов, красных цветов
  и чувства вины.
- **Сортировка и архив** — по проценту выполнения или вручную порядок;
  архивные цели исключены из процентов и всегда в конце.
- **Сроки** — к цели можно прикрепить дату, но без давления дедлайнов.
- **Резервная копия** — экспорт/импорт всего дерева и фотографий в один
  JSON, доступны без входа в аккаунт; после импорта — отчёт восстановления.
- **Три темы** — тёмная, светлая и розовая.
- **Работает офлайн** — устанавливается как приложение (PWA),
  версия видна в футере.
- **Синхронизация** — вход по email синхронизирует прогресс между
  устройствами (опционально, через Firebase).
- **Русский и English** — переключение в один клик.
- **Мотивирующие цитаты** — случайная цитата с кнопкой обновления.

## Технические решения

- Один статичный файл на чистом HTML/CSS/JS — без сборки и фреймворков.
- Хостинг на GitHub Pages.
- Синхронизация — Firebase Authentication + Firestore (опционально);
  правила доступа в `firestore.rules`, деплой одной командой.
- Фото доски «У меня будет» — сырые байты в документах Firestore
  (потолок 800 КБ при лимите документа 1 МиБ); Firebase Storage намеренно
  не используется — на бесплатном плане его не включить без привязки карты.
- Тесты — встроенный `node:test` + `jsdom` для клик-тестов (337 штук),
  CI на GitHub Actions при каждом push: юнит, клик-сценарии, guard-тесты
  (CSS-инварианты, локали, a11y, отсутствие мусора после `</html>`).
- Без аккаунта данные хранятся локально в браузере.

## Что показывает этот проект

- Продуктовые решения и их реализация с помощью ИИ: от идеи до работающего
  приложения на хостинге.
- Базовое понимание PWA и Service Worker, обеспечивающих работу офлайн
  (офлайн-first стратегия, валидация ассетов, безопасное обновление кэша).
- Работа с Firebase (Auth + Firestore) как с бэкендом, с помощью ИИ.
- Простой, понятный UX без лишнего.
- **Работа с багами, найденными на реальном устройстве:** журнал ошибок
  установленного PWA (залипший `:hover` на таче, перепутанный `order`
  в узком вьюпорте) — каждый баг разобран до причины и закрыт
  регрессионным guard-тестом.
- **Аудит качества:** 14 пунктов аудита удобства закрыты за 15 коммитов —
  тап-таргеты ≥44px, aria-pressed на тоглах, контраст по WCAG,
  `prefers-reduced-motion`, защита фокуса и скролла при перерисовке.
