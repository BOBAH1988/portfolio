# Скриншоты

Здесь хранятся изображения для витрины портфолио.

## Что положить

| Файл | Что на нём | Куда вставляется |
|---|---|---|
| `actions-log.png` | Лог GitHub Actions с зелёными галочками успешных запусков | `mail-automation.md` |
| `workflow-graph.png` | Граф workflow из раздела Actions | `mail-automation.md` |
| `app.png` | Скриншот работающего приложения (goal-tracker, love-play) | В карточку проекта в `README.md` |

## Требования к скриншотам

1. **Обезличить перед сохранением.** В логах Actions видны email, имена
   и названия компаний — обрежьте или замажьте их. Лог с утечкой
   обесценивает всю обезличенную витрину.
2. Не показывать содержимое писем клиентов и файлов с суммами.
3. Ширина — до 1200 px, формат PNG.
4. Имя файла — строчными буквами через дефис, без пробелов.

## Как вставить

В `mail-automation.md`, в раздел «Результаты»:

```markdown
![Лог GitHub Actions: успешные запуски](screenshots/actions-log.png)
```

Ссылка относительная — работает и на GitHub, и при локальном просмотре.
