# Трекер целей — PWA для пошагового достижения целей

**Демо:** [bobah1988.github.io/goal-tracker](https://bobah1988.github.io/goal-tracker/)  
**Стек:** Vanilla JS, HTML/CSS, PWA, Service Worker, Firebase (Auth + Firestore),  
node:test + jsdom  
**Версия:** v1.3.0 (20.10.2026), 373 автоматических теста в 18 модулях

## Идея

Перепробовал много сервисов постановки целей — все страдали одним: 
дедлайны давят, SMART обязателен, графики отвлекают от главного. 
Сделал свой трекер: **только цель и путь к ней**, без давления и рамок.

## Функционал

- **Дерево целей** — цель делится на подцели любой вложенности,
  прогресс считается автоматически от выполненных шагов.
- **Шаблоны** — панель «Шаблоны» в шапке открывает шесть готовых наборов
  (здоровье, работа, обучение, финансы, отношения, отдых): галочками
  отмечаешь нужные цели, они добавляются к существующей сфере или создают
  новую, повторы пропускаются.
- **Чек-листы** — к любому шагу можно прикрепить список мелких пунктов;
  частично отмеченный чек-лист даёт дробный вклад в прогресс (2/4 = половина).
- **Три важных дела на сегодня** — короткий чек-лист на день прямо на
  главном экране: капсула настроения по числу выполненного
  («Начнём?» → «Отличный день!») и дата последней правки.
- **Колесо баланса** — обзор всех сфер на одном экране, нажатие на сектор
  открывает дерево целей (и само раскрывает свёрнутый блок). Печать на A4
  одной страницей: список сфер в ровную сетку + само колесо во всю ширину;
  шеринг PNG 1080×1080 в мессенджеры (Web Share с фолбэком в файл).
- **Челлендж** — необязательный блок под колесом: привычка или цель
  на каждый день с календарём отметок, срок 7/14/21/30 дней или «без
  срока». Прошедший день без отметки помечается красным ✗ и исправляется
  одним тапом; календарь ужат до пяти строк без потери дней месяца.
  Есть прогресс-полоса, счётчик «выполнено X из Y» и обратный отсчёт;
  название меняется без потери отметок, «⟲» начинает новый челлендж
  только после подтверждения.
- **Хорошее сегодня** — необязательный дневник: запись о хорошем, история
  по 7 записей на страницу, переход к нужной дате, правка и удаление
  с подтверждением; ниже — «Победы за неделю» (три вопроса недельной
  рефлексии, архив отчётов по неделям, переход по неделям).
- **«У меня будет»** (бывшая «Карта желаний») — доска мечтаний: карточки
  «картинка + подпись», крупный просмотр, порядок вручную («↕» поднимает,
  «→» ставит на место), метка «Это я» всегда первая, плотность сетки
  2/3/4 (4 в вебе, 3 в установленном приложении), печать на A4 в цветах
  темы. Фото синхронизируются между устройствами через Firestore
  (отдельные документы, сырые байты, потолок 800 КБ), локально
  кэшируются в IndexedDB — офлайн работает.
- **Главное меню** — центрированная модалка в стиле сайта: пункты
  превращены в компактные плитки с иконками, переключатели языка и темы
  собраны в один ряд таблеток с акцентной заливкой выбранного варианта.
- **Настройка блоков** — в меню можно скрыть лишние блоки главного экрана
  («Три важных дела», «Главные цели», «Важные сферы жизни», «Колесо баланса»,
  «Челлендж», «У меня будет», «Хорошее сегодня»): содержимое не удаляется,
  блок просто не рисуется и возвращается той же настройкой.
- **Поиск** — по названиям целей и пунктам чек-листов, с путём до совпадения
  (включая архив).
- **Приоритеты** — звёздочка ☆ выносит цель или пункт чек-листа в блок
  «Главные цели», максимум 5 одновременно.
- **Мягкое напоминание о сферах** — если к сфере две недели не возвращались,
  одно ненавязчивое предложение заглянуть. Без дедлайнов, красных цветов
  и чувства вины.
- **Сортировка и архив** — по проценту выполнения (по убыванию/возрастанию)
  или вручную; архивные цели исключены из процентов и всегда в конце.
- **Сроки** — к цели можно прикрепить дату, но без давления дедлайнов.
- **Резервная копия** — экспорт/импорт всего дерева и фотографий в один
  JSON, доступны без входа в аккаунт; после импорта — отчёт восстановления.
- **Три темы** — тёмная, светлая и розовая.
- **Работает офлайн** — устанавливается как приложение (PWA),
  версия видна в футере.
- **Синхронизация** — вход по email синхронизирует прогресс между
  устройствами (опционально, через Firebase).
- **Русский и English** — переключение в один клик.
- **Мотивирующие цитаты** — случайная цитата с кнопкой обновления в блоке
  «Путь к балансу»; перед текстом подставляется имя владельца, если оно
  задано в аккаунте.

## Технические решения

- Один статичный файл на чистом HTML/CSS/JS — без сборки и фреймворков.
- Хостинг на GitHub Pages.
- Service Worker офлайн-first: навигация отдаётся из кэша мгновенно,
  ассеты валидируются по маркерам (страница-заглушка оператора не
  затирает рабочий кэш), обновление предлагается по согласию пользователя
  и не может оставить приложение без файлов.
- Синхронизация — Firebase Authentication + Firestore (опционально);
  правила доступа в `firestore.rules`, деплой одной командой.
- Фото доски «У меня будет» — сырые байты в документах Firestore
  (потолок 800 КБ при лимите документа 1 МиБ); Firebase Storage намеренно
  не используется — на бесплатном плане его не включить без привязки карты.
- Модули изолированы: «Хорошее сегодня», «У меня будет», «Челлендж»
  и настройки блоков живут рядом с деревом целей, но не влияют на колесо,
  приоритеты и итоги.
- Тесты — встроенный `node:test` + `jsdom` для клик-тестов (373 штуки
  в 18 модулях), CI на GitHub Actions при каждом push: юнит, клик-сценарии,
  guard-тесты (CSS-инварианты, локали, a11y, отсутствие мусора после
  `</html>`).
- Без аккаунта данные хранятся локально в браузере.

## Что показывает этот проект

- Продуктовые решения и их реализация с помощью ИИ: от идеи до работающего
  приложения на хостинге.
- Базовое понимание PWA и Service Worker, обеспечивающих работу офлайн
  (офлайн-first стратегия, валидация ассетов, безопасное обновление кэша).
- Работа с Firebase (Auth + Firestore) как с бэкендом, с помощью ИИ.
- Простой, понятный UX без лишнего.
- **Работа с багами, найденными на реальном устройстве:** журнал ошибок
  установленного PWA — 11 разобранных случаев (залипший `:hover` на таче,
  перепутанный `order` в узком вьюпорте, зум iOS при фокусе на поле ввода,
  нативная подсветка нажатия на iOS) — каждый баг доведён до причины
  и закрыт регрессионным guard-тестом.
- **Итерация по обратной связи владельца:** продуктовые правки (главное
  меню в виде центрированной модалки с плитками, настройка блоков,
  челлендж) доведены до продакшена серией релизов v1.2.67–v1.2.80 и
  общим релизом v1.3.0 — каждая версия закрыта тестом-сторожем,
  а не «на глаз».
- **Аудит качества:** 14 пунктов аудита удобства закрыты за 15 коммитов —
  тап-таргеты ≥44px, aria-pressed на тоглах, контраст по WCAG,
  `prefers-reduced-motion`, защита фокуса и скролла при перерисовке;
  перед снятием нативного вида кнопок проведён аудит всех 125 кнопок.
