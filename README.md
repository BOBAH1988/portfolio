### 📦 Система рекомендаций к заказу

**Пробная эксплуатация.** Используется как помощник при подготовке заказа 
зоотоваров.  
**Исходный код:** приватный репозиторий, доступен по запросу.

Началось с рабочей проблемы: товара не хватало, отдел закупок отвечал, что 
он есть, и показать нехватку цифрами вручную было невозможно. Система 
сравнивает прайс, продажи и остатки и выдаёт приоритизированный список 
того, что стоит заказать в первую очередь, с оценкой потерь в деньгах.

Система формирует приоритизированную рекомендацию для менеджера,
а не окончательный заказ поставщику.

**Технологии:** Python, openpyxl, xlrd, PyYAML, Excel, pytest.  
**Подход:** AI-assisted development с использованием Cline; требования,
проверка логики и приемка результата — со стороны автора.  
**Результат:** обработка 26 745 позиций; 3 009 товарных позиций выявлены
системой как требующие проверки доступности по актуальной выгрузке, из них
113 критичных. Оценочная потенциальная потеря выручки по расчётной модели —
около 1,04 млн ₽ в месяц.  
**Проверка:** 115 автоматических тестов, 25 итераций доработки по проекту.
