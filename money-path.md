# Денежный путь (Money-Path) — PWA для личных финансов

**Демо:** [BOBAH1988.github.io/Money-Path](https://BOBAH1988.github.io/Money-Path/) · **Репозиторий:** [BOBAH1988/Money-Path](https://github.com/BOBAH1988/Money-Path)

**Стек:** React, TypeScript, Vite, Firebase Authentication, Cloud Firestore

## Задача

Собрать в одном приложении повседневный учёт личных финансов: планировать
бюджет, фиксировать доходы и расходы, вести активы и обязательства и
просматривать историю доходов. Приложение должно оставаться доступным
офлайн, а синхронизация между устройствами — быть необязательной.

## Решение

Money-Path — клиентское PWA. Гостевой режим хранит данные локально в
браузере; вход в аккаунт Firebase добавляет облачную синхронизацию.
Интерфейс и локально сохранённые данные доступны без постоянного
подключения к сети.

### Возможности

- **Бюджет:** плановые и фактические расходы, ежемесячные и дополнительные
  категории, автоматический пересчёт итогов.
- **Финансовые записи:** активы, обязательства, доходы и архив доходов.
- **Дашборд:** сводка доходов, расходов, активов и обязательств, а также
  архив доходов по месяцам.
- **Импорт и экспорт:** JSON-архив с предварительной проверкой и
  восстановлением данных.
- **Офлайн-работа:** локальные данные, кэш аккаунта и очередь изменений,
  ожидающих синхронизации.
- **Аккаунт:** вход по email и паролю, восстановление доступа и удаление
  аккаунта.
- **PWA:** установка на устройство, адаптивный интерфейс, светлая и тёмная
  темы.

## Технические решения

- **React и TypeScript** — интерфейс и типизированная логика приложения.
- **Vite** — локальная разработка и production-сборка для GitHub Pages.
- **Firebase Authentication и Cloud Firestore** — аккаунты и хранение
  данных пользователей.
- **localStorage, IndexedDB и Service Worker** — локальные данные, очередь
  синхронизации и кэш приложения.
- **Vitest, Testing Library и jsdom** — модульные и компонентные тесты;
  Firebase Emulator Suite используется для тестов правил Firestore.
- **Импорт и экспорт JSON** — пользователь может перенести данные или
  восстановить их из резервной копии.

## Что показывает этот проект

- Проектирование клиентского приложения с локальным режимом и облачной
  синхронизацией.
- Учёт офлайн-сценариев и сохранение изменений до восстановления сети.
- Работу с Firebase Authentication, Firestore и правилами доступа.
- Разработку и публикацию устанавливаемого PWA на GitHub Pages.

Приложение предназначено для учёта и планирования и не является финансовой
или инвестиционной рекомендацией. Перед массовым импортом или изменениями
данных рекомендуется создать резервную копию.
