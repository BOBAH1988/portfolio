# Учебные проекты GeekBrains

Практика по профессии «Аналитик» — сентябрь 2024 — февраль 2025.

## 1. Дипломный проект: «Влияние социальных медиа на потребительское поведение»

**Задача:** проанализировать, как соцсети влияют на потребительские 
решения.

**Что делал:**
- Собрал данные из открытых источников.
- Обработал и проанализировал через Python (Pandas).
- Провёл анализ тональности упоминаний.
- Визуализировал выводы.

**Результат:** выявил ключевые факторы влияния в соцсетях, 
сформулировал практические рекомендации для маркетинговых стратегий.

**Стек:** Python, Pandas, визуализация.

## 2. Финансовый анализ и моделирование

**Задача:** оценить прибыльность продуктовых линий через сценарии 
«что-если».

**Что делал:**
- Рассчитал ключевые метрики: выручка, маржа, ROMI.
- Построил сценарии «что-если» для оценки влияния изменений.
- Создал модель для планирования и принятия решений.

**Результат:** определил прибыльные и убыточные продуктовые линии, 
создал модель для стратегического планирования.

**Стек:** Excel, Google Sheets.

## 3. Настройка отчётности для контроля продаж

**Задача:** упростить ежедневный контроль продаж и остатков.

**Что делал:**
- Адаптировал Excel-отчёты под свои задачи в FMCG.
- Сделал удобные для ежедневного использования шаблоны.

**Результат:** сократил время на подготовку данных, освободил ресурс 
для анализа и работы с клиентами.
