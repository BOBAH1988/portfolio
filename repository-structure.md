# Структура репозитория

```text
portfolio/
├── README.md                    ← главная страница портфолио
├── mail-automation.md           ← автоматизация почтовых процессов
├── order-recommendations.md     ← система рекомендаций к заказу
├── vba-macros.md                ← автоматизация Excel с помощью VBA
├── goal-tracker.md              ← PWA «Трекер целей»
├── love-play.md                 ← PWA с играми
├── geekbrains.md                ← учебные аналитические проекты
├── repository-structure.md      ← этот файл
└── screenshots/                 ← обезличенные изображения
    ├── README.md                ← правила подготовки скриншотов
    └── actions-log.png          ← лог GitHub Actions
```

## Назначение файлов

- `README.md` — главная страница и краткая витрина портфолио.
- `mail-automation.md` — описание автоматизации почтовых процессов.
- `order-recommendations.md` — описание системы рекомендаций к заказу.
- `vba-macros.md` — описание Excel-макросов.
- `goal-tracker.md` — описание PWA-трекера целей.
- `love-play.md` — описание PWA с играми.
- `geekbrains.md` — учебные аналитические проекты.
- `repository-structure.md` — описание структуры репозитория.
- `screenshots/` — обезличенные изображения для демонстрации проектов.

## Принцип организации

Репозиторий намеренно плоский: каждая страница проекта — отдельный файл
в корне. Посетитель открывает `README.md` и переходит по прямой ссылке
на нужный проект, не погружаясь в лишние уровни вложенности.
